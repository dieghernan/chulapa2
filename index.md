# chulapa2

A Jekyll theme built with Bootstrap 6.

## About

chulapa2 is the independent successor to [chulapa](https://dieghernan.github.io/chulapa/).
It keeps the Chulapa typeface and rebuilds the theme for Bootstrap 6.
